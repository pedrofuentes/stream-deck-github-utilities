How to create a token

A fine-grained personal access token is recommended for the best security.

1 Go to Settings → Developer settings → Fine-grained tokens
2 Click Generate new token
3 Select the repositories you want to monitor, then grant these permissions:
Metadata — read (required for Repo Stats, Commit Activity)
Actions — read (required for Workflow Status)
Deployments — read (required for deployment tracking)
Pull requests — read (required for PR Counter)
Issues — read (required for Issue Counter)
Contents — read (required for Release Monitor, Branch Comparison)
ℹ Alternatively, create a classic token with the repo scope for full access to all repositories (including private).
4 Click Generate token and paste it above
